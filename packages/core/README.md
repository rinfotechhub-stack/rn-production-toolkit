# @rn-production-toolkit/core

Typed errors, retry with backoff/cancellation, a pluggable logger with safe
redaction, and React Native adapter contracts (lifecycle, network, device).

- **Runtime dependencies:** none.
- **License:** MIT.
- **Documentation:** see the repository `README.md`, `docs/ARCHITECTURE.md`,
  `docs/API.md`, `docs/COMPATIBILITY.md`, and `docs/DECISIONS.md` in
  `rn-production-toolkit` for full API references, examples, compatibility, and
  decisions.
