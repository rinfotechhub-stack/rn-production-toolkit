# Support

For versioning rules, support lifecycle windows, and migration guidelines, see [`SUPPORT_POLICY.md`](SUPPORT_POLICY.md).

## Quick Reference

- **Security issues:** Please report privately following [`SECURITY.md`](../SECURITY.md).
- **Bug reports & feature requests:** Open an issue using the [GitHub issue templates](../.github/ISSUE_TEMPLATE/).
- **Supported versions:** Until `1.0.0`, only the latest `0.x` release is actively supported.
- **Questions & Community:** Open a discussion or issue in the GitHub repository.
